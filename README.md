## 왜 만들었나

학생회 임원은 매 학기 바뀌지만, 지켜야 할 규정은 회칙·세칙 여러 건에 흩어져 있습니다. 사업 하나를 하려면 규정을 찾고, 총회 양식에 맞춰 사업계획서와 예산안을 쓰고, 합계와 예비비를 손으로 맞추고, 사례금 원천징수나 개인정보 동의 같은 법령까지 따로 확인해야 합니다.

진짜 원인은 **정보가 없어서가 아니라 확인할 곳과 순서가 너무 많아서**입니다. 그래서 몰라서 규정을 어기고, 계산 실수가 감사에서 처분으로 돌아오는 일이 반복됩니다.

이 프로젝트는 그 과정을 **질문 하나와 문서 한 번 올리기**로 대체합니다. 규정은 조항 단위 출처와 함께 답하고, 금액·합계·날짜는 **코드가 계산**하며, 법령은 **법제처 원문과 대조한 조문만** 근거로 보여 줍니다.

## 어떻게 동작하나

규정 질문은 **멀티에이전트 RAG**로, 업무 도구는 **추출은 모델·계산은 코드·근거는 원문 대조**로 나눠 처리합니다.

```mermaid
flowchart LR
    subgraph QA[규정 질문]
        Q[질문] --> R[질문 분류]
        R -->|규정 질의| S[하이브리드 검색<br/>키워드 + 벡터]
        R -->|범위 밖| G[안내]
        S --> A1[규정 검토]
        S --> A2[감사 분석]
        A1 --> C[종합 조정]
        A2 --> C
        C --> ANS[답변 · 근거 조항 · 위험도]
    end
    subgraph TOOLS[업무 도구]
        F[문서 · 개요 · 법령 질문] --> X[모델: 구조 추출 · 문장 초안]
        X --> K[코드: 합계 · 예비비 · 날짜 계산]
        K --> V[원문 대조: 회칙·세칙 / 법제처 조문]
        V --> OUT[점검 결과 · Word · 엑셀]
    end
```

- **멀티에이전트:** 규정 검토와 감사 분석을 두 에이전트가 동시에 수행하고, 조정 에이전트가 하나의 권고로 종합합니다. 최종 위험도는 두 판정 중 높은 쪽을 코드가 고릅니다.
- **계산은 코드:** 문서 검토와 기획 도우미는 표 합계, 수입−지출, 예비비 10% 한도, 요일까지 코드가 다시 계산해 어긋난 곳만 알려 줍니다.
- **근거 대조:** 규정 메모는 실제로 검색된 조항만, 법령 답변은 법제처 원문으로 확인된 조문만 근거로 남기고 나머지는 지웁니다.
- **개인정보:** 질문·문서의 이름·전화번호·계좌는 모델에 보내기 전과 저장 전에 코드로 가립니다. 올린 파일 원본과 업무 도구 결과는 저장하지 않습니다.

### 배포 구조

```mermaid
flowchart LR
    U[학생회 임원] --> W[Vercel<br/>Next.js 웹]
    W -->|API| A[Railway<br/>FastAPI · ChromaDB · SQLite]
    A --> CL[Claude API]
    A --> GE[Gemini 임베딩]
    CL -->|MCP| LAW[법제처 법령 MCP]
    A -->|인용 대조| LAW
```

규정 색인은 서버가 아니라 로컬에서 만들어 옮깁니다. 큰 감사보고서도 시간 제한 없이 색인하고, 로컬과 운영 색인이 똑같아 검증 결과가 그대로 운영에 적용됩니다.

## 실제 예시

> **질문 (법령 점검표 · 참가자 개인정보):** 행사 사진을 인스타그램에 올리려면 참가자 동의를 받아야 하나요?
>
> **답변:** 행사 사진에 참가자를 알아볼 수 있는 얼굴이나 영상이 담겨 있다면 개인정보에 해당해요. 개인정보처리자가 이를 제3자에게 제공하려면 원칙적으로 정보주체의 동의가 필요해요. … 학생회가 개인정보처리자에 해당하는지와 사진이 식별 가능한지는 사안마다 달라서 직접 판단하기 어려워요.
>
> 확인할 것 — 사진으로 참가자를 알아볼 수 있는지 / 동의받을 때 목적·항목·보유 기간·거부 권리를 함께 알리기 / 학생회 회칙·세칙의 사진 게시 절차는 규정 질문에서 확인
>
> **근거:** 「개인정보 보호법」 제2조(정의) · 제15조(개인정보의 수집·이용) · 제17조(개인정보의 제공) — 세 조문 모두 법제처 원문과 대조해 시행일과 원문 링크를 붙임

| **기⁠획 도⁠우⁠미** | 행사 개요를 넣으면 총회 양식 사업계획서·예산안 초안을 만듭니다. 목적·주요 활동은 AI 초안으로 채울 수 있고, 금액·예비비·일정은 코드가 계산합니다. |

| **법⁠령 질⁠문** | 점검표에 없는 질문은 법제처 법령에서 조문을 찾아 답하고, 인용 조문을 원문과 대조해 링크를 붙입니다. |
| **내 작⁠업⁠함** | 기획 초안·검토 결과·회의록을 서버가 아닌 내 브라우저에 30일간 보관합니다. |
| **공⁠지·일⁠정** | 총회 공고 같은 일정을 홈 화면과 상단 공지로 알립니다. |

## 주의

- 학생회 업무를 돕는 참고 도구이며, 학생회 공식 해석이나 법률·세무 자문을 대신하지 않습니다. 중요한 결정은 원문과 담당 기관·전문가로 확인하세요.
- 규정 검색에 쓰는 회칙·세칙·감사보고서와 총회 제출 자료는 저장소에 포함하지 않습니다.
- 측정값은 위 기준일의 색인·평가셋 기준이며, 규정이 개정되거나 색인이 바뀌면 달라질 수 있습니다.
