# 규정 문서 폴더

여기에 **학생회칙, 세칙, 정기감사 보고서 등 PDF 파일**을 넣어주세요.

## 색인 방법

PDF를 넣은 뒤 아래 명령 한 번이면 전부 색인됩니다 (이미 색인된 파일명은 자동으로 건너뜀):

```bash
cd api
.venv\Scripts\python.exe ingest_folder.py
```

또는 웹 UI의 **문서 관리** 페이지(http://localhost:3000/admin)에서 개별 업로드해도 됩니다.

## 참고

- 텍스트 레이어가 있는 PDF만 지원합니다. 스캔본(이미지) PDF는 현재 색인되지 않으며, 변환 후 넣어주세요.
- 이 폴더의 PDF는 git에 커밋되지 않습니다 (내부 문서 보호).
